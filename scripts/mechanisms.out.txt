======== §7 用户模拟器带来的方差 ========
Lost in Simulation 表：同一 agent 换 4 个用户模型，成功率极差 = 8.9 点，模型间标准差 = 4.06
  而同一用户模型 3 次重跑的标准差只有 1.2–3.5 点 → 换模拟器的影响大于重跑噪声
  τ² airline : 模拟器致命错误 13% → 若这些对话被判失败，分数最多被低估约 13 点（上界，非估计值）
  τ² retail  : 模拟器致命错误 12% → 若这些对话被判失败，分数最多被低估约 12 点（上界，非估计值）
  τ² telecom : 模拟器致命错误 6% → 若这些对话被判失败，分数最多被低估约 6 点（上界，非估计值）
pass^k 独立假设 p=0.7:  [0.7, 0.49, 0.24, 0.058]
pass^k 若模拟器对 10% 任务系统性带偏(pass^1 仍=0.7): [0.7, 0.518, 0.293, 0.096]  → pass^k 衰减变慢，k 越大差越多

======== §9 预训练：NLL → bits-per-byte ========
10 个 token、每 token 平均 NLL 2.3 nats、44 字节 → BPB = 10×2.3/(ln2×44) = 0.7541
换一个分词器（20 个 token、每 token 1.15 nats）BPB 不变: 0.7541 → 这就是跨分词器比较用 BPB 的原因
